# Mycelial Network Visualizer

Interactive web-based visualization for mycelium-inspired neural networks. Built with React, D3.js, and Vite.

This visualization tool is designed to work with the [mycelium_network](https://github.com/angrysky56/mycelium_network) library.

## Overview

This tool provides real-time visualization of network topology, training metrics, and ecosystem dynamics for mycelial networks. The visualization runs in the browser and connects to data generated by the mycelium network library.

## Features

- **Network Graph**: Interactive force-directed visualization with drag-and-drop positioning, zoom/pan controls, and node inspection
- **Learning Metrics**: Training progress tracking including rewards, losses, exploration rates, and Q-table monitoring
- **Ecosystem View**: Population dynamics and energy flow visualization for organism-based simulations
- **Customization**: Five color schemes, adjustable physics parameters, and flexible node/connection styling

## Prerequisites

- Node.js 18 or higher
- Python 3.8 or higher
- [mycelium_network](https://github.com/angrysky56/mycelium_network) library

Install the mycelium network library:

```bash
git clone https://github.com/angrysky56/mycelium_network.git
cd mycelium_network
pip install -r requirements.txt
```

## Installation

```bash
npm install
```

For the Python API server:

```bash
pip install flask flask-cors
```

## Usage

### Generate Network Data

Run one or more demo scripts to generate visualization data:

```bash
python generate_network_demo.py
python train_network_demo.py
python adaptive_network_demo.py
python generate_learning_demo.py
python generate_ecosystem_demo.py
```

These scripts create JSON files in the `public/` directory.

### Start the Visualization

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

### Optional: Run API Server

For real-time integration with Python:

```bash
python api_server.py
```

The API server runs on port 8000 and provides endpoints for network creation, training, and visualization data export.

## Data Format

### Network Data

```json
{
  "nodes": [
    {
      "id": 0,
      "type": "input|output|regular|storage|processing|sensor",
      "position": [0.5, 0.5],
      "activation": 0.8,
      "energy": 0.9,
      "resource_level": 1.2,
      "age": 10
    }
  ],
  "connections": [
    {
      "source": 0,
      "target": 3,
      "strength": 0.7
    }
  ]
}
```

### Learning Data

```json
{
  "trainingData": {
    "epochs": [0, 1, 2],
    "rewards": [0.5, 0.6, 0.7],
    "losses": [0.8, 0.6, 0.4],
    "explorationRate": [1.0, 0.95, 0.9]
  },
  "qTable": {}
}
```

### Ecosystem Data

```json
{
  "organisms": [
    {
      "id": "plant_0",
      "type": "plant|herbivore|decomposer",
      "position": [0.3, 0.7],
      "energy": 0.8,
      "size": 1.0
    }
  ],
  "energyFlow": {
    "photosynthesis": 25.0,
    "consumption": 12.0,
    "decomposition": 8.0
  }
}
```

## Customization

### Color Schemes

Five built-in schemes: Neural, Organic, Scientific, Cyberpunk, Monochrome. Change via the control panel or edit `src/lib/colorSchemes.js`.

### Node Visualization

Adjust node appearance through the control panel:
- Color by: type, activation, energy, specialization
- Size by: fixed, activation, resources, energy, age
- Opacity control
- Label toggles

### Physics Parameters

Control force-directed layout behavior:
- Node repulsion strength
- Link distance
- Center force
- Collision radius

## Integration with Existing Code

From mycelium network scripts:

```python
from mycelium.network import AdvancedMyceliumNetwork
from mycelium.environment import Environment

env = Environment()
network = AdvancedMyceliumNetwork(environment=env)

# ... training code ...

# Export for visualization
network.visualize_network(filename='path/to/Mycelial_Vis/public/network_data.json')
```

For adaptive networks:

```python
from mycelium.enhanced.adaptive_network import AdaptiveMyceliumNetwork
from mycelium.enhanced.rich_environment import RichEnvironment

env = RichEnvironment()
network = AdaptiveMyceliumNetwork(environment=env)

# ... training code ...

vis_data = network.visualize_network_data()
import json
with open('path/to/Mycelial_Vis/public/adaptive_network.json', 'w') as f:
    json.dump(vis_data, f)
```

Refresh the browser to load the new data.

## API Endpoints

When running the API server:

- `POST /api/network/create` - Create a new network
- `POST /api/network/<id>/forward` - Run forward pass
- `POST /api/network/<id>/train` - Train the network
- `GET /api/network/<id>/visualize` - Get visualization data

## Development

```bash
npm run dev      # Start dev server
npm run build    # Build for production
npm run preview  # Preview production build
```
